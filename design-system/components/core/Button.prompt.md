Primary action button. Square corners (radius 0), flat fills, no shadow — hover darkens via opacity, never a color swap.

```jsx
<Button variant="default" size="lg">Explore Directory</Button>
<Button variant="outline">Secondary action</Button>
```

Variants: `default` (black fill), `outline` (1px border), `secondary` (light gray), `ghost` (transparent), `destructive`, `link` (underlined text, no box). Sizes: `default`, `sm`, `lg`, `icon` (40×40 square).

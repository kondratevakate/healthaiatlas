# Code of Conduct

This project adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) without modification. The full text is available at the linked source and is incorporated here by reference.

## Reporting

To report a concern under this code, contact the project owner at the email listed on the public site About page. Reports are reviewed promptly and treated with discretion.

## Scope

This code applies to all project spaces — the GitHub repository, issue tracker, pull requests, any future community channels (Slack / Discord), and project-related conversations on third-party platforms when contributors are identifiable as participating in this project.

## Enforcement

Violations may result in warnings, removal of contributions, or ban from the project. Decisions are made by the project owner.

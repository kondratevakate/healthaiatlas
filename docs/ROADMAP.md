## Open contribution roadmap

We expect community contributions to focus on three areas:

1. **Data corrections + additions** to `frontend/src/data/` (players, claims, domains, conferences, mentors, resources). All contributions require evidence URLs and confidence levels — see [`CONTRIBUTING.md`](../CONTRIBUTING.md).
2. **Methodology improvements** — proposed refinements to how we source, verify, and refresh data. Discussed in GitHub issues.
3. **Translations** — Arabic; later French and Spanish.

We do **not** accept contributions for the professional tier — that is a closed-source service. The public layer is open.

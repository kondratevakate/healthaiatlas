# HealthAI Atlas — Public layer and Professional tier

HealthAI Atlas operates with two layers. The public layer is freely accessible open knowledge. The professional tier funds ongoing development.

## The principle

> **Public layer = proof of authority and recency.**
> **Professional tier = decision-ready data infrastructure for institutional users.**

The two layers are not the same content with different gating. They serve different needs.

## Public layer (open / free)

Anyone can browse, reference, cite, and share — under the project's [open-knowledge license](../../LICENSE).

| Feature | What it includes |
|---|---|
| Company directory | Names, categories, locations, brief descriptions, latest news mention |
| Categorization framework | Taxonomy of AI applications, deployment status types, regulatory status taxonomy |
| Ecosystem map visualization | Interactive map showing relationships between organizations |
| News aggregation | Recent funding events, deployments, regulatory milestones, product launches with summaries |
| Annual public report | Free download |
| Methodology documentation | How HealthAI Atlas sources, verifies, and refreshes data |
| Sample data slices | Demonstrative entries for evaluating fidelity |
| Coming-soon waitlists | For each region not yet covered |

## Professional tier

Provides commercial-use rights and decision-ready data infrastructure to institutional users.

| Feature | What it includes |
|---|---|
| Structured data export | CSV / Excel / API access to verified records |
| Quarterly comprehensive updates | Major data refresh as advertised deliverable |
| Direct analyst access | Submit specific research questions, receive structured response within 48 hours |
| Custom analyses | Reports customized for client-specific questions |
| Members community | Slack / Discord access for paying members |

## Why the boundary matters

The two layers have different licenses (see [`LICENSE`](../../LICENSE)). The public layer is licensed for non-commercial use; commercial use requires a professional tier subscription, which carries an explicit commercial-use license and additional services.

For commercial subscription details, contact the project owner via the email on the [About page](https://healthaiatlas.com/about) (live URL when public site ships).
